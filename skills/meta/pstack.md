# pstack
- category: meta
- post link: https://x.com/poteto/status/2106542593656111276; https://x.com/poteto/status/2119521036660314339
- github link: https://github.com/cursor/plugins/tree/main/pstack
- description: @poteto's skill pack for high-quality agent coding (poteto-mode, /correct, /architect, /recall, /sharpen, /benchmark-checklist and more). The 0.15.9 release post adds /correct, which turns repeated corrections into architecture, types and checks; @DmitriyLeybel also posted an Opus-written deep dive on it. The state-machine follow-up pairs /create-formal-verification-skill, which generates project-local checks for a scoped property, with /statechart, which checks TLA+ models and visualizes user flows as Mermaid statecharts with shortest paths to rule violations.
